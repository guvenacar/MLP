# My First MLP Project 🚀

Hoş geldiniz! Bu, MLP (Multi-Language Programming) dilinde yazılmış ilk projeniz.

## 📁 Proje Yapısı

```
my-first-mlp-project/
├── src/
│   └── main.mlp          # Ana program dosyası (hesap makinesi)
├── examples/
│   ├── hello.mlp         # Basit Hello World örneği
│   ├── loops.mlp         # Döngü ve koşullar örneği
│   └── class-example.mlp # OOP sınıf örneği
├── README.md             # Bu dosya
└── build.sh              # Derleme scripti
```

## 🚀 Hızlı Başlangıç

### Ana Programı Çalıştırma

```bash
# Derleme ve çalıştırma (build.sh kullanarak)
./build.sh

# Manuel derleme (MLP compiler ile)
mlp src/main.mlp -o calculator
./calculator
```

### Örnekleri Çalıştırma

```bash
# Hello World
mlp examples/hello.mlp -o hello
./hello

# Döngüler ve koşullar
mlp examples/loops.mlp -o loops
./loops

# Sınıf örneği
mlp examples/class-example.mlp -o class-demo
./class-demo
```

## 📚 Ne Öğreneceksiniz?

### 1. **main.mlp** - Hesap Makinesi
- Fonksiyon tanımlama
- Matematiksel işlemler
- Değişkenler ve veri tipleri
- Ekrana çıktı verme

### 2. **hello.mlp** - Hello World
- En basit MLP programı
- YAZDIR komutu kullanımı

### 3. **loops.mlp** - Döngüler ve Koşullar
- DÖNGÜ (while loop) kullanımı
- EĞER (if/else) koşullu ifadeler
- Sayısal değişkenler

### 4. **class-example.mlp** - OOP Örneği
- Sınıf tanımlama (SINIF)
- Constructor (KURUCU)
- Metodlar (IŞLEÇ)
- Nesne oluşturma (YENİ)

## 🔧 MLP Temel Anahtar Kelimeler

| Türkçe | İngilizce | Açıklama |
|--------|-----------|----------|
| YAZDIR | PRINT | Ekrana çıktı verir |
| SINIF | CLASS | Sınıf tanımlar |
| IŞLEÇ | FUNCTION | Fonksiyon tanımlar |
| KURUCU | CONSTRUCTOR | Constructor tanımlar |
| DÖNGÜ | WHILE | While döngüsü |
| EĞER | IF | If koşulu |
| DEĞILSE | ELSE | Else koşulu |
| DÖNÜŞ | RETURN | Değer döndürür |
| YENİ | NEW | Yeni nesne oluşturur |
| BU | THIS | this pointer |
| SAYISAL | NUMBER | Sayısal veri tipi |
| METIN | STRING | Metin veri tipi |
