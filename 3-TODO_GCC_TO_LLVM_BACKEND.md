## 🎯 HEDEF

mlp-original Stage0-C compiler'ın backend'ini x86-64 Assembly'den LLVM IR'a migrate etmek.

**Neden?**
1. Platform bağımsızlığı (x86, ARM, RISC-V, etc.)
2. LLVM optimizer'dan faydalanmak (-O3 optimizations)
3. Modern toolchain (lli, llc, lldb)
4. MLP-LLVM'deki 1 aylık emek boşa gitmesin
5. Future-proof backend

**Önkoşul:**
- ✅ ADIM 1 tamamlanmalı (TODO_STAGE0_PMLP_SYNTAX.md)
- ✅ ADIM 2 tamamlanmalı (TODO_RUNTIME_INTEGRATION.md)
- mlp-original → PMLP syntax + Zengin runtime

**Sonuç:**
```
.mlp → LLVM IR (.ll) → Object (.o) → Executable
      ↓
      lli test.ll (interpret, instant run!)
```

### **PHASE 4: LLVM IR Codegen - Expressions** (3-4 saat) 🟡 ORTA ÖNCELİK

#### Task 4.1: Binary Operations (+, -, *, /, etc.)

**AST Node:** `AST_BINARY_OP`

**x86 ASM (Eski):**
```nasm
pop rbx     ; right operand
pop rax     ; left operand
add rax, rbx
push rax
```

**LLVM IR (Yeni):**
```llvm
%left = load i64, i64* %x
%right = load i64, i64* %y

```

**Implementation:**
```c
void generate_binary_op_llvm(ASTNode* node, FILE* output) {
    generate_expression_llvm(node->left, output);
    int left_temp = temp_id - 1;
    
    generate_expression_llvm(node->right, output);
    int right_temp = temp_id - 1;
    
    char* op_name = NULL;
    switch (node->op_type) {
        case OP_ADD: op_name = "add"; break;
        case OP_SUB: op_name = "sub"; break;
        case OP_MUL: op_name = "mul"; break;
        case OP_DIV: op_name = "sdiv"; break;
        default: error("Unknown operator");
    }
    
    fprintf(output, "  %%t%d = %s i64 %%t%d, %%t%d\n", 
            temp_id++, op_name, left_temp, right_temp);
}
```

### **PHASE 5: LLVM IR Codegen - Control Flow** (4-5 saat) 🟡 ORTA ÖNCELİK

#### Task 5.1: If Statements

**AST Node:** `AST_IF`

**LLVM IR:**
```llvm
; if x > 5 then ... else ... end_if
%cond = icmp sgt i64 %x, 5
br i1 %cond, label %if.then, label %if.else

if.then:
  ; then block
  br label %if.end

if.else:
  ; else block
  br label %if.end

if.end:
  ; continue
```

**Implementation:**
```c
void generate_if_statement_llvm(ASTNode* node, FILE* output) {
    static int label_id = 0;
    int current_label = label_id++;
    
    // Generate condition
    generate_expression_llvm(node->condition, output);
    int cond_temp = temp_id - 1;
    
    // Compare (0 = false, non-zero = true)
    fprintf(output, "  %%cond%d = icmp ne i64 %%t%d, 0\n", current_label, cond_temp);
    fprintf(output, "  br i1 %%cond%d, label %%if.then%d, label %%if.else%d\n",
            current_label, current_label, current_label);
    
    // Then block
    fprintf(output, "\nif.then%d:\n", current_label);
    generate_statement_list_llvm(node->then_body, output);
    fprintf(output, "  br label %%if.end%d\n", current_label);
    
    // Else block
    fprintf(output, "\nif.else%d:\n", current_label);
    if (node->else_body) {
        generate_statement_list_llvm(node->else_body, output);
    }
    fprintf(output, "  br label %%if.end%d\n", current_label);
    
    // End label
    fprintf(output, "\nif.end%d:\n", current_label);
}
```

| Risk | Olasılık | Çözüm |
|------|----------|-------|
| LLVM IR syntax hatası | Orta | Referans .ll dosyalarını takip et |

| Backward compatibility | Çok Düşük | `-backend=asm` default |
